# Archivo (variable)

The interface typeface. A single grotesque with two variable axes, `wdth` 62-125 and
`wght` 100-900: the same file sets the condensed rail labels and the prose at normal
width, without loading a second family.

Self-hosted on purpose. The application runs locally and must not depend on an external
CDN to draw itself.

License: SIL Open Font License 1.1 (see `OFL.txt`). Copyright of the Archivo authors;
redistributed here under the terms of that license.

Subsets, with the same `unicode-range` Google Fonts serves:
- `archivo-latin.woff2`      U+0000-00FF and punctuation (covers English and Spanish)
- `archivo-latin-ext.woff2`  extended Latin
- `archivo-vietnamese.woff2` Vietnamese
